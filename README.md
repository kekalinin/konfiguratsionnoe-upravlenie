# Эмулятор оболочки

Эмулятор командной оболочки UNIX-подобной ОС
с графическим интерфейсом.

## Описание

Проект реализует эмулятор shell на Python
с использованием tkinter. Поддерживает парсер
команд с кавычками, логирование и стартовые
скрипты.

## Возможности

- Графический интерфейс в стиле терминала
- Парсер команд с поддержкой кавычек
- Логирование событий в JSON
- Стартовый скрипт с комментариями
- Команды: ls, cd, conf-dump, exit

## Параметры командной строки

| Параметр      | Описание          |
|---------------|-------------------|
| --vfs ПУТЬ    | Путь к файлу VFS  |
| --log ПУТЬ    | Путь к файлу лога |
| --script ПУТЬ | Путь к скрипту    |
