# Эмулятор оболочки

Эмулятор командной оболочки UNIX-подобной ОС
с графическим интерфейсом.

## Описание

Проект реализует эмулятор shell на Python
с использованием tkinter. Поддерживает парсер
команд с кавычками, логирование и стартовые
скрипты.

## Возможности:

- Графический интерфейс в стиле терминала
- Парсер команд с поддержкой кавычек
- Логирование событий в JSON
- Стартовый скрипт с комментариями
- Команды: ls, cd, conf-dump, exit

## Параметры командной строки

| Параметр      | Описание          |
|---------------|-------------------|
| --vfs ПУТЬ    | Путь к файлу VFS  |
| --log ПУТЬ    | Путь к файлу лога |
| --script ПУТЬ | Путь к скрипту    |

## Виртуальная файловая система (VFS)

Эмулятор поддерживает работу с виртуальной файловой
системой, загружаемой из JSON-файла. Все операции
производятся в памяти, исходный файл не изменяется.

### Формат VFS (JSON)

```json
{
  "type": "dir",
  "name": "root",
  "children": [
    {
      "type": "file",
      "name": "hello.txt",
      "content": "SGVsbG8="
    }
  ]
}

## Основные команды (Этап 4)

- `uptime` — время работы эмулятора
- `head [-n кол-во] <файл>` — первые N строк файла (по умолчанию 10)
- `tac <файл>` — содержимое файла в обратном порядке (снизу вверх)
- `mv <источник> <назначение>` — переместить/переименовать файл или папку
- `cp <источник> <назначение>` — скопировать файл или папку
- `ls` — список содержимого текущей папки
- `cd <путь>` — сменить папку (поддерживает `..` и `/`)
- `conf-dump` — показывает текущий путь и параметры
- `exit` — выход из эмулятора

### Примеры использования

# Показать первые 5 строк файла

# Показать содержимое файла в обратном порядке
